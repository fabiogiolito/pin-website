# Press logos

Used by `src/components/home/SectionPressLogos.astro` on the homepage and in the site-wide footer.

Logos should be single-color black on transparent so the `grayscale` CSS filter in the component reads right. Transparent PNG or SVG preferred.

Filenames referenced by `SectionPressLogos.astro` (do not rename):
- `business-insider.svg` — Business Insider
- `venture-beat.png` — VentureBeat
- `ap.svg` — Associated Press
- `digital-journal.svg` — Digital Journal

Check each outlet's press/logo usage guidelines before committing — some require prior written approval.
